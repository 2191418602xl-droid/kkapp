# ORBIT Music 高保真原型

## 产品与体验

ORBIT 面向喜欢流行、电子和氛围音乐的年轻用户，核心目标是让用户在两次点击内开始播放，并在浏览、搜索、收藏和切换页面时保持连续播放。主链路为：推荐或搜索 → 专辑/歌单 → 播放器 → 歌词/收藏/队列 → 音乐库。

信息架构由四个一级入口组成：`首页`负责快速播放与个性推荐，`发现`负责分类和榜单，`音乐库`管理收藏与下载，`我的`承载身份、会员和设置。搜索位于首页与发现页，播放器作为全局层级，通过迷你播放器持续存在。

## 视觉规范

- 画布：iPhone 16 Pro 逻辑尺寸 `402 × 874px`，圆角 `48px`。
- 风格：冷白、冰蓝、银灰与深空蓝；高质量大图作为单一视觉焦点；玻璃面板和细线控制层级。
- 交互：主按钮高度 44px，触控区域不小于 44px；底部 Tab 保留安全区；播放、收藏可交互。
- 素材：使用仓库现有真实图片资源，页面没有占位图。

直接打开 `index.html` 可平铺查看全部页面；每个页面也可独立打开。
