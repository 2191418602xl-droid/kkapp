# KIRAKIRA 高保真 HTML 原型

本原型依据 KKApp 现有功能整理，不改变现有 React 应用。核心体验是：发现世界 → 查看详情 → 进入沉浸剧情 → 与角色继续对话 → 在虚拟手机与社区延续关系 → 收藏、创作和管理个人内容。

一级导航包含世界、发现、创作者中心、消息和我的；详情、虚拟手机、角色聊天、社区、钱包等作为二级页面。视觉采用冷白、冰蓝、银紫、深空暗部和玻璃材质，使用项目已有图片资源，全部页面按 iPhone 16 Pro `402 × 874px` 设计。

打开 `index.html` 可通过 iframe 平铺查看所有界面，每个 HTML 文件也可以独立运行。
