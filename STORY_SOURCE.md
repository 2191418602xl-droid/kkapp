# Story source note

The interactive romance arc in “雨夜来信” is an original modern retelling inspired
by the misunderstanding-to-understanding courtship structure of Jane Austen's
*Pride and Prejudice* (1813).

Source edition: <https://www.gutenberg.org/ebooks/42671>

Project Gutenberg identifies this edition as public domain in the USA. No passage
from the source text is reproduced verbatim in the application.
